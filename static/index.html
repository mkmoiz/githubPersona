Available SSH keys

Select a key to save an account or activate an identity already linked to it.

Private keys are referenced by their file path. Only public keys can be copied from this app.

01

Bring your SSH keys

The app discovers private keys in ~/.ssh. Add an account to link a key with your Git author name and email. You can also enter a key path elsewhere on your machine.

Need a new key? Click Generate SSH key, choose a filename and email, and optionally protect it with a passphrase. The app creates an Ed25519 key and displays its public key.

Copy the public key and add it as an Authentication Key to the matching account in GitHub SSH settings ↗.

02

Save an identity

Give it a label like Personal or Work, then save the name and email you want on your commits. Your Git author name can differ from your GitHub username.

Use a verified GitHub email or the no-reply email shown in your GitHub email settings for commit attribution.

Saving or editing a profile does not change Git. Click Activate account to apply the saved settings.

03

Switch. Then build.

Activating an account updates these global settings together:

user.name
user.email
core.sshCommand

The SSH command selects your key with -i and IdentitiesOnly=yes. Existing SSH configuration still applies and may specify additional keys. The command applies to all Git SSH remotes.

↳

Know what is active

The current status reads global Git settings every 15 seconds. It reports a match only when the name, email, and SSH command all match a saved account.

HTTPS remotes, GitHub CLI login, and browser sessions are separate. Repository config, conditional includes, and environment variables can override global defaults.

Use Get SSH origin to create an account-specific remote such as git@github-work:owner/repo.git. Encrypted keys may need ssh-add ~/.ssh/your_key. This app shows configured identity, not verified GitHub authentication.

A backup of your global Git config is saved before each switch. Removing an account only removes its saved profile; your key file and Git configuration are kept.

Add your public key

  1. Sign in to the GitHub account this key belongs to.
  2. Open GitHub’s New SSH key page ↗.
  3. Enter a title, choose Authentication Key, paste the public key above, and click Add SSH key.

GitHub registration is completed on GitHub. Your private key stays on this computer.
A REMOTE FOR THIS ACCOUNT

Get SSH origin

Choose the repository path, then copy the origin URL or the complete setup for this account.

ACCOUNT-SPECIFIC SSH ORIGIN
git@github-account:OWNER/REPOSITORY.git
PASTE DURING INIT / SETUP
git init
git config --local user.name 'Your Name'
git config --local user.email 'you@example.com'
git config --local core.sshCommand 'ssh -i ~/.ssh/your_key -o IdentitiesOnly=yes'
git remote add origin git@github-account:OWNER/REPOSITORY.git

The host alias identifies the selected account and maps to GitHub in ~/.ssh/config. The full setup also pins this repository’s author and SSH key, so later global account switches cannot change it.
